# キャラクターと画像の設定

開発アプリを再起動すると、メニューに **CHARACTER** が追加されます。

## キャラクターを作る・編集する

1. CHARACTERを開き、登録済みキャラクターか「新規作成」を選びます。
2. 名前、説明・口調、最初の挨拶を入力します。必要なら「性格・状況・会話例」も設定します。
3. 表情ごとにID、LLMが選ぶための説明、立ち絵画像を設定し、デフォルト表情を選びます。
4. 標準背景を選び、プレビューの大きさ・左右・上下のスライダーで配置を調整します。
5. 「設定を保存」、または「保存してこのキャラで新規開始」を押します。

**NEW SESSIONは現在のキャラで即開始します。** 毎回選択画面は出ません。別のキャラを使いたい場合だけCHARACTERから開始してください。同じキャラの設定を更新した場合、NEW SESSIONでは更新後の設定を使います。

最初の挨拶はLLMを呼ばずに表示し、最初のユーザー入力時に会話履歴へ保存します。`{{char}}` / `<BOT>` はキャラクター名、`{{user}}` / `<USER>` は `YOU` へ置き換えます。挨拶を空欄にして、ユーザーから話し始めることもできます。

## 台詞と地の文

挨拶に引用符で囲まれた台詞がある場合、`"…"`、`“…”`、`「…」`、`『…』` を台詞として、その前後の文章を地の文として表示します。地の文のページでは名前欄を表示しません。台詞を囲む外側の引用符はメッセージウィンドウへの表示時に外し、台詞内部の引用や元の挨拶・カード情報は保持します。引用符のない挨拶は、従来どおり台詞として扱います。これは形式に基づく簡易判定で、文章の意味をAIで分類する処理ではありません。

すでに保存された挨拶も表示時に区別するため、カードの再読み込み・セッションの作り直しは不要です。既存の会話履歴そのものは書き換えません。

## 画像

- PNG / JPEG、1ファイル32MB以下。縦横8192px以内、合計2400万画素以内に対応します。
- 立ち絵は透過PNGを推奨します。全身・上半身の区別をアプリで固定せず、登録した構図に合わせて配置を調整します。
- 同じキャラの表情画像はサイズと人物位置を揃えてください。配置設定は全表情で共通です。
- 背景はキャラクターの標準背景として保存します。画面を覆うように表示するため、縦横比によって端が切れる場合があります。
- 画像を外した場合は、立ち絵なし／既定の背景で表示します。

画像はユーザーデータディレクトリの `assets/` にPNGとしてコピーします。元の画像を移動・削除しても影響しません。新しい画像への差し替えは別ファイルとして保存するため、既存セッションの画像は変わりません。参照切れを避けるため、現段階では使わなくなった保存画像を自動削除しません。

## Character Cardを読み込む

「カードを読み込む」からJSONまたはPNGを選びます。**ローカル解析のみで、LLMもネットワーク接続も不要**です。取り込み結果を編集画面で確認し、保存すると登録されます。

対応するのはV1のJSON、V2（`chara_card_v2` / `2.0`）のJSON、それらを `chara` のtEXtチャンクに埋め込んだPNGです。V3専用カードや、設定データのない通常のPNGはカードとしては読み込めません。通常の画像は立ち絵・背景の画像選択から登録してください。

取り込む項目：

| カードの項目  | アプリでの扱い   |
| ------------- | ---------------- |
| `name`        | 名前             |
| `description` | 説明・口調       |
| `personality` | 性格             |
| `scenario`    | 状況             |
| `first_mes`   | 最初の挨拶       |
| `mes_example` | 会話例           |
| PNGの画像     | 最初の表情の画像 |

`system_prompt`、`post_history_instructions`、`character_book`、`alternate_greetings`、`extensions` は元データに保持し、未対応の旨を表示します。現在はこれらによる会話制御は行いません。未知の項目も元データに保持しますが、SillyTavernと同じ振る舞いを完全再現するものではありません。

表情差分、標準背景、配置は、このアプリの設定画面で追加してください。画像生成や画像内の顔差分抽出は行いません。独自設定のエクスポートは未実装です。

## セッションとの関係

セッション作成時に、キャラの設定・画像参照・背景・配置をコピーします。ライブラリ側を編集・削除しても、既存セッションは変わりません。SESSION一覧から再開した場合は、そのセッションのキャラクター設定を使用します。

削除済みキャラのセッションからNEW SESSIONを開始する場合は、そのセッションに残っている設定を使います。ライブラリには少なくとも1人のキャラクターを残します。

同梱のAliceは仮のプリセットです。正式な設定・立ち絵・背景は、ユーザーが用意したものを登録して使用できます。
