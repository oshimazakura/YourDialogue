# YourDialogue

AIとの会話を、キャラクターの立ち絵・表情・文字送りを備えたビジュアルノベルのUIで楽しむデスクトップクライアントです。長い説明やコードはPHONEで読み、会話はSESSIONごとに保存できます。

開発中のプレビュー版です。Electron / React / TypeScript / SQLiteを使用しています。

## LLM接続の方針と現在の対応

OpenAI互換のChat Completions APIに対応しています。接続先のベースURL・APIキー・モデルを設定でき、認証不要のローカルサーバーではAPIキーを省略できます。OpenRouterは現在の開発・テストに使用している接続先で、URLの初期値にしています。

接続先は `POST /chat/completions` のStreamingと、本文のJSONL出力に対応している必要があります。モデル一覧は `GET /models` の `data` 配列から取得します。一覧を取得できない接続先では、理由を表示してモデルIDの手入力に切り替えられます。APIの互換性やモデルの出力には差があり、一覧に載っていても会話できるとは限りません。Responses APIや各社独自APIの専用対応は未実装です。

## 開発・起動

Node.js 24以上とnpmを用意してください。

```sh
npm install
npm run dev
```

次の手順で接続先とモデルを設定します。

1. **CONFIG → AI・API**で、利用するサービスの接続先URLを入力します。ベースURLは `https://example.com/v1` のように指定し、`/chat/completions` や `/models` は付けません。
2. 接続先のAPIキーを入力します。認証不要の場合は空欄にします。保存済みの接続先を開くとモデル一覧を取得します。URL・キーを変更した場合は**モデル一覧を取得・更新**を押します。
3. モデル名・IDで検索して選択し、**設定を保存**します。取得に失敗した場合はURL・キーを修正して再取得するか、モデルIDを手入力できます。一覧取得は未保存の設定でも試せます。
4. **会話に戻る**からメッセージを送信します。別の会話を始める場合は**NEW SESSION**を選びます。

接続先URLを変更すると、以前のサービスのAPIキーは引き継ぎません。変更後の接続先に必要な場合は新しいキーを入力してください。旧版の設定は、OpenRouterのURL・選択済みモデル・保存済みキーをそのまま引き継ぎます。

送信時にはキャラクター設定と会話履歴を指定した接続先へ送ります。API利用の料金・条件は接続先および利用モデルのものに従います。APIキーは同梱していません。

```sh
npm test           # Node標準テストランナーで通信解析・保存・会話制御を検証
npm run typecheck  # TypeScriptの型チェック
npm run lint       # ESLintで未使用変数などを検査
npm run format     # Prettierでコード整形
npm run build      # main / preload / rendererをdistへビルド
npm start          # ビルド済みのElectronアプリを起動
npm run package    # 現在のOS向けの配布用アプリをreleaseへ生成
```

Reactの変更は開発中に反映されます。main / preloadを変更した場合は開発プロセスを再起動してください。初回の `npm install` は依存パッケージとElectron本体をダウンロードします。生成された `package-lock.json` はコミット対象です。

## 操作

- **Enter**で送信、**Shift + Enter**で改行。日本語変換中のEnterでは送信しません。
- 送信した直近の入力を会話欄の上に残し、返答が届くとフェードアウトします。返答待ちの間は前の会話を維持し、表示可能な返答が届くと切り替えます。通知は右上に表示します。
- 発話欄のクリックで現在ページを即時表示し、もう一度クリックすると次のページへ進みます。受信と文字送りは独立しています。
- **PHONE**にコード・Markdown・詳しい説明が届きます。スクロール、選択、コピーができます。
- **LOG**からBACKLOGを開き、会話全文を確認・コピーできます。過去のユーザー発言の編集は、その後の履歴を破棄して再生成します。
- **停止**は生成を中断します。完成したJSONオブジェクトは保存し、未完成のものは破棄します。
- **CONFIG**で文字送り速度・文字サイズ・決定音を変更できます。
- **CONFIG → キャラクター**でキャラクター設定、最初の挨拶、表情画像・背景の登録、配置プレビュー、Character Cardの読み込みができます。NEW SESSIONは現在のキャラで即開始します。

## セッションと保存

- **NEW SESSION**で現在のキャラの新しい会話を開始します。左端の＋、または⌘/Ctrl+Nでも開始できます。
- 最初のメッセージを送ると、挨拶とともに**SESSION**一覧へ保存されます。送信前の下書きは一覧に追加されず、切替・終了で破棄されます。
- 以後の会話は完成したJSONオブジェクトごとに自動保存します。SESSION一覧から再開・名前変更・削除できます。
- 起動時は最後に選択していた保存済みセッションを復元します。生成中の終了・クラッシュ後は、残った回答を中断として扱います。
- セッション切替・編集・再生成では、先に現在の生成を停止します。編集前の履歴には戻れません。

データはElectronのユーザーデータディレクトリ内の `dialogue.sqlite` に保存します。macOSの標準位置は `~/Library/Application Support/YourDialogue/` です。会話履歴は暗号化していません。APIキーは会話履歴とは分離し、OSの `safeStorage` で暗号化します。安全な保管機能を利用できない環境では、キーはメモリ内だけに保持します。キーを変更せず設定を保存すると、現在のキーを維持します。

## JSONLプロトコル

表示内容は、LLMが生成するJSONLで受け取ります。Chat CompletionsのSSE応答から `delta.content` の本文を取り出します。JSONオブジェクトが完成し、検証に成功したものだけを画面・SQLiteへ渡します。モデルが改行を省いて `}{` のように連結しても、文字列・エスケープ・入れ子を区別して個別に読み取ります。改行や回答全体の生成完了は待ちません。未完成のオブジェクトは保持し、停止・切断時には破棄します。

```jsonl
{"type":"speech","expression":"face_02","text":"コードはスマホに送ったよ。PHONEから見てね。"}
{"type":"phone","format":"code","language":"typescript","text":"const value = 1;"}
```

台詞は `speech`、地の文は `{"type":"narration","text":"描写"}` で出力します。地の文では名前欄を表示せず、直前の表情を維持します。

PHONEの `format` は `text` / `markdown` / `code`。本文の改行は `\n` としてエスケープします。各モデルがJSONLを生成できるかは実際のモデルで確認してください。JSONモードは単一JSON文書を要求する場合があるため、使用せず、システムプロンプトで形式を指定しています。不正な行はスキップして通知し、不明な表情IDはデフォルトに戻します。HTTPエラー、生成途中のエラー、長さ制限、切断は回答状態に記録し、BACKLOGや再生成から対処できます。自動リトライはしません。

## 構成

```text
src/core/        JSONL・SSE解析、LLM接続、SQLite、会話制御
src/main/        Electronウィンドウ、限定IPC、APIキー管理
src/preload/     rendererへ公開する型付きAPI
src/renderer/    VN画面、ページ分割、各パネル
src/shared/      共有データ型と仮キャラクター設定
public/characters/alice/  仮の表情付きSVG立ち絵
tests/          通信・セッション保存・編集・復元・ページ分割のテスト
docs/           仕様書・利用ガイド・診断ガイド
design/ui-prototype/  HTML/CSSによる画面デザイン案
```

キャラクターはCONFIG内のキャラクター画面で管理し、SQLiteに保存します。同梱の仮プリセットは `src/shared/character.ts` で定義しています。ユーザーが登録した画像はアプリのユーザーデータディレクトリへコピーし、セッションには設定・画像参照・背景・配置を保存します。詳しい手順とCardの対応範囲は [docs/characters.md](docs/characters.md) を参照してください。

## 現在の対応範囲

OpenAI互換APIの接続先設定・モデル一覧取得と選択、通常のテキスト会話、表情切替、VNのページ送り、シンプルなPHONE、BACKLOG、編集・再生成、セッション自動保存・一覧からの再開を実装しています。

Character Card V1/V2のJSON/PNG読み込み、キャラクター管理、最初の挨拶、画像・背景登録、立ち絵の配置プレビューも実装しています。

添付ファイル、Web検索、外部ツール実行、PDF・画像ビューア、TTS、配布用の署名・自動更新は後続対応です。PHONEのMarkdownはHTMLを実行せず、外部画像・リンク遷移も無効にしています。履歴の自動要約・削減は行わず、長さ上限のエラー時には新しいセッションへ移ってください。

開発方針と仕様は [docs/specification.md](docs/specification.md) にまとめています。未実装の構想も含むため、現在使える機能はこのREADMEの対応範囲を参照してください。

## 不具合の診断

開発時はローカル診断APIが起動し、受信・JSONL解析・保存・ページ送りの状態とイベント、保存済み／編集中のキャラクター情報を取得できます。まず状態とログで調査し、スクリーンショットは必要な場合のみ取得します。開発用の診断ファイルには生の返答やキャラクター設定が含まれるため、不具合報告に添付する前に内容を確認してください。curlの使い方とログの説明は [docs/diagnostics.md](docs/diagnostics.md) を参照してください。
